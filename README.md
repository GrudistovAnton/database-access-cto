# База данных СТО (MS Access)

Пример базы данных для станций технического обслуживания.

## Что внутри:

- Таблицы: Автомобили, Марка авто, Владельцы, Заказы, Услуги, Состав заказа, Мастера
- Формы для ввода и просмотра данных с кнопочной навигацией
- Запросы для поиска и отчетов
- Главная кнопочная форма (меню)

## Технологии

- MS Access 2007
